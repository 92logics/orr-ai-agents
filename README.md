# ORR Knowledge & Workforce agents (prototype)

Scripted sample by [92 Logics](https://www.92logics.com) for the Office of Rail and Road Artificial Intelligence Innovation opportunity (ORR CT 26-34). It is not an official ORR system and not a bid.

## Buyer and notice

- Buyer: Office of Rail and Road
- Notice: https://www.find-tender.service.gov.uk/Notice/090514-2026

## What it shows

A labeled sample of the Corporate Knowledge Agent and the Strategic Workforce Planning Agent named in the notice (knowledge discovery, evidence retrieval, expertise identification; workforce forecasting, scenario modelling, resource planning). Answers are scripted from that public notice page. Questions the notice does not cover are refused. Nothing calls a live AI service.

## Run it

Open `index.html` in a browser. No install and no build step.
